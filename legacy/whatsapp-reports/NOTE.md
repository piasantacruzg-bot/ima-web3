# Legacy tool: IMA WEB3 Reportes (Google Sheets)

This is the original lightweight reporting tool that predates the Creator
Campaign OS rebuild. It reads/writes a Google Sheets "master sheet" and
tracks Telegram/WhatsApp post links.

It has been moved here (not deleted) so its history and code stay available.
It is **not** wired into the new Next.js app router structure at the repo
root, which now hosts Creator Campaign OS. If this legacy tool needs to run
again standalone, its routes/components/lib can be copied back into a
top-level `app/` directory, or it can be extracted into its own project.

See `README.md` in this folder for its original setup instructions.
